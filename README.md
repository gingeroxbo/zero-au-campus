# De zéro au campus

Manuel d'anglais interactif pour francophones (A1 à C1), en app iPhone utilisable hors connexion.
Site statique publié avec GitHub Pages. Pour l'installer : ouvrir l'adresse du site dans Safari, puis Partager, puis « Sur l'écran d'accueil ».

- `index.html` : l'app
- `contenu.json` : les 27 unités, le plan sur 24 semaines et les verbes irréguliers
- `sw.js` : le fonctionnement hors connexion

La progression (réponses, scores) reste sur l'appareil ; l'app propose une sauvegarde et une restauration par fichier.
